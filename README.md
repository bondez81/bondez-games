## How to install
1. Open a release below and download the APK.
2. Allow installation from this source when Android asks.
3. Start the game — no internet, no account.

## Checksums
SHA-256 of every build is in [sha256.md](sha256.md) and in each release body.

## Sources
Each game is a self-contained offline web build shipped inside a thin Android shell.
APKs are attached to releases on purpose: no binaries in git history.
